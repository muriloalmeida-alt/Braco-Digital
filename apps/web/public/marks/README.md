# Marcas de integração (WhatsApp, Google Calendar, Google Tasks)

Usadas na landing pública só para indicar compatibilidade/integração —
nunca para sugerir parceria ou endosso oficial do BRAÇO por essas
empresas (docs/design/26-growth-landing-experience.md,
docs/technical/05-whatsapp.md, 06-google-calendar.md, 07-google-tasks.md).

- `whatsapp.svg` — glifo oficial simplificado do WhatsApp (cor oficial
  `#25D366`), via [Simple Icons](https://simpleicons.org/) (CC0).
- `google-calendar.svg` — ícone oficial colorido do Google Calendar,
  obtido diretamente de `fonts.gstatic.com/s/i/productlogos/...`
  (hospedado pelo próprio Google).
- `google-tasks.svg` — glifo simplificado do Google Tasks, via
  [Simple Icons](https://simpleicons.org/) (CC0), recolorido para o
  azul oficial do Google (`#4285F4`) — não foi possível localizar o
  ícone colorido oficial completo (rede deste ambiente de
  desenvolvimento não alcança os domínios do Google onde ele estaria
  hospedado, fora `fonts.gstatic.com`). **Revisar/substituir por um
  asset oficial completo quando disponível.**

Nenhum desses arquivos foi redesenhado — apenas reproduzidos como
publicados por suas respectivas fontes, com a cor de marca oficial
aplicada onde o arquivo de origem é monocromático.
