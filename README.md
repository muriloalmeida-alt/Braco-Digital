# BRAÇO

**Mais capacidade para sua empresa.**

Funcionários digitais que trabalham junto com sua equipe.

> **Sua empresa precisa de mais um braço? Agora tem.**

## O que é
BRAÇO é uma plataforma de funcionários digitais para pequenas empresas.

O cliente não compra IA, chatbot, automação, prompts ou APIs. Contrata uma função capaz de executar trabalho com responsabilidade, limites claros e resultado mensurável.

> Tem trabalho demais. Nem todo trabalho precisa de uma pessoa. Mas todo trabalho importante precisa de alguém responsável por ele.

## Posicionamento
- Unidade de venda: **funcionário**
- Unidade de expansão: **mais funcionários**
- Estratégia: **entrada vertical, expansão horizontal**
- Primeiro funcionário: **Braço Atendimento**
- Vertical inicial de aprendizado: clínicas e prestadores de serviço
- Canal de comunicação com clientes: **WhatsApp**
- Área gerencial: **BRAÇO**
- Recursos operacionais: **Google Calendar** e **Google Tasks**

> **O gestor usa o BRAÇO. O funcionário trabalha. O cliente conversa pelo WhatsApp.**
