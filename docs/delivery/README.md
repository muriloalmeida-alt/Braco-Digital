# BRAÇO — Delivery

Esta pasta traduz os PRDs aprovados em artefatos operacionais.

> **Docs definem. Issues operacionalizam. Código implementa.**

## Estrutura
- `backlog.md`
- `story-index.md`
- `issue-creation-guide.md`
- `epics/`
- `sprints/`

## Fonte de verdade
1. decisão formal mais recente;
2. PRD;
3. épico;
4. história;
5. issue.

Mudança de comportamento retorna ao PM.

## Design Ready

Histórias com impacto de interface devem referenciar a documentação de `docs/design/`.

O gate de início é:

> **Product Ready + Design Ready + Tech Ready**

Design é parte da prontidão da história, não uma etapa opcional posterior.
