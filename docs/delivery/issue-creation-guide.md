# BRAÇO — Guia de criação de GitHub Issues

## Título
`USXX — Nome da história`

## Corpo
- contexto;
- história de usuário;
- critérios de aceitação;
- regras de negócio;
- dependências;
- fora do escopo;
- referências.

## Labels sugeridas
- `product`
- `user-story`
- épico
- sprint
- prioridade

## Regra
A issue não substitui a documentação.

> **Docs definem. Issues operacionalizam. Código implementa.**
