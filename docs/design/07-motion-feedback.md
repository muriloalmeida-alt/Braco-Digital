# BRAÇO — Motion e Feedback

## 1. Princípio

Motion deve explicar mudança, não decorar.

## 2. Padrão

Usar motion padrão do Material para:

- navegação;
- expansão;
- dialogs;
- feedback;
- mudanças de estado.

## 3. Expressive

Motion mais expressivo pode ser considerado para:

- contratação concluída;
- ativação de funcionário;
- mudança para Trabalhando;
- onboarding;
- conclusão de preparação.

Evitar motion expressivo em:

- listas operacionais densas;
- logs;
- alertas urgentes;
- intervenção humana;
- telas de monitoramento contínuo.

## 4. Feedback

Toda ação relevante precisa indicar:

- processamento;
- sucesso;
- falha;
- resultado.

Usar padrões M3 apropriados:

- progress indicator;
- snackbar;
- dialog;
- inline validation.

## 5. Optimistic UI

Somente usar quando a reversão for segura e previsível.

Ações como agendamento, ativação, integrações ou envio ao cliente devem refletir o estado real confirmado.
