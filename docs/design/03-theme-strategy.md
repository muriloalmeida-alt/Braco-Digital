# BRAÇO — M3 Theme Strategy

## 1. Direção

O tema deve comunicar:

- confiança;
- capacidade;
- clareza;
- proximidade;
- simplicidade;
- profissionalismo;
- humanidade.

Evitar:

- cyber/AI;
- neon;
- futurismo gratuito;
- excesso de gradientes;
- glassmorphism;
- densidade corporativa pesada;
- estética de dashboard técnico.

## 2. Estratégia de tema

O BRAÇO utiliza M3 com identidade de marca controlada.

As seeds provisórias anteriores ficam substituídas pela identidade oficial.

### Primary seed

**Azul BRAÇO — `#0B4F86`**

Uso:

- primary;
- CTA principal;
- foco;
- seleção;
- elementos institucionais de maior prioridade.

### Secondary seed

**Cinza Médio — `#66717D`**

Uso:

- suporte;
- componentes secundários;
- informação não prioritária;
- geração de roles secundários neutros.

### Tertiary seed

**Verde Capacidade — `#32B44A`**

Uso semântico:

- sucesso;
- trabalhando;
- conectado;
- concluído;
- ganho de capacidade;
- resultado positivo.

Não usar verde como CTA genérico.

### Brand dark

**Azul Profundo — `#07345A`**

Uso:

- navegação;
- fundos escuros;
- áreas de alta hierarquia;
- aplicação da logo negativa.

Não precisa substituir roles M3 globais.

Pode existir como token de marca específico para o App Shell.

## 3. Superfícies

Light theme deve preservar a identidade neutra oficial:

- background principal: `#F7F9FA`;
- cards/superfícies de contraste: `#FFFFFF`;
- texto principal: `#1C2530`;
- texto secundário: `#66717D`;
- bordas: `#E8ECEF`.

O M3 continua responsável pelos roles e estados.

## 4. Tema claro e escuro

Produto suporta:

- Light Scheme
- Dark Scheme

### Light

É a expressão de marca primária do produto e deve respeitar os neutros
oficiais acima.

### Dark

Pode ser derivado algoritmicamente das seeds oficiais pelo M3.

No modo escuro:

- manter reconhecimento da marca;
- usar logo negativa;
- preservar contraste;
- não transformar o verde em cor dominante.

## 5. Dynamic Color

Dynamic Color não é requisito para o produto web.

## 6. Gradientes

Gradiente não é recurso padrão do produto.

Permitido de forma pontual em:

- login;
- onboarding;
- superfícies institucionais.

Gradiente institucional permitido:

`#07345A → #0B4F86`

Azul → verde deve ser raro e nunca dominar a aplicação.

## 7. Proporção visual

Como referência de composição:

- 60% branco/off white;
- 25% azul;
- 10% cinzas;
- 5% verde.

Não interpretar como medição literal por tela.

É uma regra de equilíbrio visual.

## 8. Expressividade

A identidade vem primeiro de:

1. clareza;
2. conteúdo;
3. cor;
4. tipografia;
5. shape;
6. espaço;
7. motion.

Motion é complementar.

## 9. Objetivo emocional

A interface deve parecer:

> **uma ferramenta de trabalho moderna feita para ajudar pessoas reais.**
