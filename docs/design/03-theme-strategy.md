# BRAÇO — M3 Theme Strategy

## 1. Direção

O tema deve comunicar:

- confiança;
- capacidade;
- clareza;
- proximidade;
- profissionalismo.

Evitar estética:

- cyber/AI;
- neon;
- futurismo gratuito;
- excesso de gradientes;
- excesso de glassmorphism;
- densidade corporativa pesada.

## 2. Estratégia de tema

O BRAÇO utilizará tema M3 com paleta de marca controlada.

### Seed principal proposta
**BRAÇO Blue — `#3156A3`**

Função:
- primary;
- foco;
- ações principais;
- seleção;
- estados ativos.

### Seed secundária proposta
**Slate — `#586578`**

Função:
- suporte visual;
- elementos secundários;
- organização.

### Seed terciária proposta
**Teal — `#006B5E`**

Função:
- sucesso operacional;
- trabalho ativo;
- informação complementar.

## 3. Tema claro e escuro

O produto deve nascer preparado para:

- Light Scheme
- Dark Scheme

As telas não devem hardcodar cores de fundo, texto ou borda.

Sempre consumir semantic roles.

## 4. Dynamic Color

Dynamic Color não é requisito de identidade para o produto web.

Se uma implementação nativa Android utilizar Dynamic Color, isso deve ser tratado como decisão técnica e não pode destruir reconhecimento da marca ou semântica operacional.

## 5. Expressividade

A identidade vem primeiro de:

1. cor;
2. tipografia;
3. shape;
4. composição;
5. conteúdo.

Motion expressivo é camada complementar.
