# Fluxo 05 — Agenda e Agendamento

## Objetivo
Permitir transformar conversa em compromisso sem conflito.

## Fluxo

```text
Necessidade identificada
→ Consultar disponibilidade
→ Oferecer horários
→ Cliente escolhe
→ Validar disponibilidade
→ Criar agendamento
→ Confirmar ao cliente
→ Registrar no trabalho
```

## Regras
- nunca oferecer horário sabidamente indisponível;
- revalidar quando necessário antes da confirmação;
- comunicar sucesso apenas após confirmação real;
- tratar falhas de integração.

## Alteração

```text
Agendamento existente
→ Solicitar alteração
→ Consultar nova disponibilidade
→ Selecionar novo horário
→ Atualizar
→ Confirmar
```

## Cancelamento

Comunicar impacto antes de concluir quando aplicável.

## Superfície gerencial
Mostrar:
- cliente;
- serviço;
- data/hora;
- origem;
- status;
- funcionário responsável.

## Compact
Agenda prioriza lista e ações.

## Expanded
Pode combinar calendário + detalhe/lista quando útil.
