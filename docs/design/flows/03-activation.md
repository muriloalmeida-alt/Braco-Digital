# Fluxo 03 — Ativação

## Objetivo
Garantir que somente funcionário pronto entre em operação.

## Fluxo

```text
Preparação concluída
→ Status Pronto
→ Checklist de ativação
→ Revisar pendências
→ Ativar funcionário
→ Confirmação
→ Status Trabalhando
```

## Checklist

Itens típicos:
- Manual de Trabalho completo;
- WhatsApp configurado;
- agenda configurada quando aplicável;
- responsáveis definidos;
- regras críticas definidas.

## Regra
> **Não trabalhar é melhor do que trabalhar errado.**

## Ação Ativar

Só disponível quando condições obrigatórias forem atendidas.

## Feedback
Após ativação:
- mudança visual de estado;
- confirmação;
- explicação do que acontece agora.

## Estados
- incompleto;
- pronto;
- ativando;
- ativo;
- erro de ativação;
- integração precisa de atenção.

## M3
- Checklist composition
- Buttons
- Dialog apenas se impacto justificar
- Progress
